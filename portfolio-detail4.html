Apple-Inspired Interactive Storefront

A responsive Apple-inspired storefront and product showcase built with React and Vite, designed to recreate a modern, immersive product-shopping experience. The project includes multiple product and category pages, responsive navigation, interactive shopping-bag functionality, animated UI sections, and interactive 3D MacBook and iPad Pro product experiences.

I used React Router for navigation, Zustand and React Context for state management, Three.js with React Three Fiber and Drei for 3D product rendering, and GSAP for smooth animations and transitions. The project also uses reusable React components, CSS modules, custom hooks, structured data files, and Vite for development and production builds.

Building the 3D configurators pushed me to connect UI state, animation timing, and WebGL rendering in one flow. It was one of the most rewarding front-end projects I’ve worked on so far.
